# The Symmetry Core

*The dihedral group, the stabilizer, and the group computing with itself.*

---

## 2. The symmetry core

The rigid symmetries of a square form the dihedral group **D4** (8 elements): identity, three rotations (90/180/270), two axis mirrors (horizontal, vertical), two diagonal mirrors (main, anti). The group is **injected** into the Plexus, so the group choice (full D4 vs a subgroup) lives in one place — the caller. Each `Transform` is parameterized by the grid **frame** (`rows × cols`), so the same machinery acts on any size of square grid (full D4) **and on rectangular grids** (the transpose-free subgroup **D2** = `{identity, rot180, mirrorH, mirrorV}`, `Dihedral.d2()`; [§11](appendices/A-mathematical-background.md), *the rectangle*). On a square frame the `(rows, cols)` primitive reduces to the single-side formula, so the square path is unchanged.

---

### Fundamental domains (octants)

The four reflection axes are four lines through the centre at 45° spacing, cutting the square into **8 wedges** — the fundamental domains, one per group element. Routing by symmetry is **collapsing a shape onto its fundamental domain**: the more symmetry it has, the smaller the wedge it folds into.

---

### Canonical stabilizer

A shape's symmetry is its **stabilizer** — the subset of the group that fixes it (`SymmetryGroup.stabilizer`). To make the descriptor orientation-free, the symmetry verdict is the **rotation-canonical stabilizer**: the minimum stabilizer bitmask over the grid's rotations (`canonicalStabilizer`, stepping by the group's `minimalRotation`). This folds a shape and its rotated copies onto one key — the **one degeneracy kept on purpose** (rotation of a genuine shape), because it gives the class enough members to be coherent.

A shape is **radial** if some non-trivial rotation fixes its centred form (`rotationFixes`) — a round object (dot, plus) with no meaningful orientation. Radial shapes take a different branch ([§4](02-core-model.md)).

---

### Multiplication: the group computing with itself

Everything above **acts**: it applies transforms to grids, one at a time. Multiplication is the other half — the ability to **name the composite** rather than merely perform it. `rot90 ∘ rot90 = rot180`, `mirrorH ∘ mirrorV = rot180`; the `=` is the content, asserting that the composite is *already in the set* and saying which element it is. With it the group can compute with itself, answering questions about symmetry **sets** with no grid present.

It costs no new geometry, because `Transform.src` already **is** the permutation. From the contract `out[i] = in[src(i)]`:

```
src_(a∘b)[i] = src_b[ src_a[i] ]
```

so `multiplicationTable()` reads straight off the existing primitive on a 3×3 probe frame — a scratch pad only, since the group structure is frame-independent (D2 composes identically on a square, so it borrows the same probe). From the table: `compose`, `inverse`, `closure` (the subgroup **generated by** a mask), `isSubgroup`, and `canonicalMask` — the mask-level twin of `canonicalStabilizer`, folding the symmetry *names* by rotation-conjugacy with no grid involved.

**What it is for: telling three kinds of nothing apart.** Ask for a symmetry and get no contexts back, and the answer could mean any of three unrelated things — indistinguishable without the multiplication surface:

| absence | cause | decided by |
|---|---|---|
| **impossible** | the mask isn't closed, so it is not a subgroup and *no* shape can have it (`mirrorH` + `mirrorV` without `rot180`) | `isSubgroup` — group algebra alone |
| **dead spelling** | achievable, but canonicalization always renames it: under D4 `{identity, mirrorV}` is stored as `{identity, mirrorH}` | `canonicalMask` — group algebra alone |
| **unpopulated** | legal, canonical, askable — this dataset just has none | whatever remains |

The distinction reaches the surface in two places: `SymmetrySlice` explains an empty result rather than returning a bare `0 matching contexts`, and `[1]`'s posed mode reports an impossible stabilizer as impossible for any shape, not merely unachieved by *this* one. Requesting a non-closed set in a *containment* query is repaired rather than rejected — keeping `mirrorH` and `mirrorV` silently means keeping `rot180`, so the slice closes the request and says so.

The group lives in `org.tervel.plexus.symmetry`: `Transform` (one rigid grid→grid map, `extends UnaryOperator<int[]>`, frame-parameterized by `(rows, cols)`), `SymmetryGroup` (stabilizer, canonicalStabilizer, rotationFixes — each with a `(rows, cols)` overload — plus minimalRotation, rotations, describe, and the multiplication surface: multiplicationTable, compose, identityIndex, inverse, closure, isSubgroup, canonicalMask), `Dihedral.d4()` (square) and `Dihedral.d2()` (rectangle), and `Crystallographic` (the covering/non-covering split).
